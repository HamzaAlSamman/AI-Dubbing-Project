# معايير قبول Translation V2

تُكتب هذه المعايير **قبل** تشغيل V2 على بيانات الاختبار، ولا تُعدَّل بعد رؤية النتائج. أي تعديل يُكتب في آخر الملف مع سببه وتاريخه.

**تُقاس كل المعايير:**
- على **بيانات الاختبار** (دروس لم تُستخدم في التطوير)، لا على المحاضرة الحالية.
- على **مجموعات المصدر المتكافئة**.
- مع فترة ثقة 95%.

«غير أسوأ» = الحد الأدنى لفترة ثقة الفرق لا يتجاوز هامش عدم الدونية المذكور.

## أ. شروط هندسية (كلها إلزامية)

| # | الشرط | طريقة التحقق |
|---|---|---|
| A1 | كل الاختبارات تنجح في CI، ومنها T1–T13 | GitHub Actions |
| A2 | التشغيل الكامل ينتهي بلا `degraded`، ولا وحدات «مؤجلة» | الـ manifest |
| A3 | إعادة التشغيل بالإعدادات والكاش أنفسهما تعطي ملف نهائي مطابق (بايت ببايت ما عدا الطوابع الزمنية) | مقارنة hash |
| A4 | الـ manifest يحتوي:<br>- hash المصدر قبل التجهيز وبعده<br>- hash كل برومبت<br>- إصدارات الحزم<br>- لقطة الذاكرة<br>- الكلفة والزمن | فحص آلي |
| A5 | كل مخرج نهائي يطابق مخطط عقد TTS | JSON Schema |
| A6 | لا مفتاح API في المستودع ولا في المخرجات | فحص CI |

## ب. شروط المعنى (إلزامية)

| # | الشرط | المقياس |
|---|---|---|
| B1 | V2 غير أسوأ من V1 في المعنى | chrF++ وCOMET بمرجع بشري؛ هامش عدم الدونية: 1 نقطة chrF++ و0.01 COMET |
| B2 | V2 غير أسوأ من أفضل نموذج منفرد (B1) في المعنى | مثل B1 |
| B3 | حفظ الأرقام والمتغيرات والنفي ≥ 99% من الحالات | فحص آلي، وتدقيق يدوي لـ 100 حالة |
| B4 | لا إضافة محتوى غير موجود في المصدر في ≥ 98% من الوحدات | مراجعة بشرية لعينة 100 وحدة، مصنّفة بـ MQM: Addition |
| B5 | لا حذف لمعلومة تعليمية في ≥ 97% من الوحدات | مثل B4، الفئة Omission |
| B6 | الحَكَم المستقل (عائلة غير مستخدمة في الخط) لا يفضّل V1 على V2 بدلالة | اختبار ثنائي على الوحدات غير المتعادلة |

## ج. شروط العربية والدبلجة (إلزامية)

| # | الشرط | المقياس |
|---|---|---|
| C1 | دقة المصطلحات ≥ 95% على قاموس التقييم البشري المستقل، وأفضل من V1 بدلالة | `eval_glossary` |
| C2 | ثبات المصطلح عبر دروس الكورس ≥ 95% (المصطلح المتكرر بالترجمة نفسها) | على 3 دروس متتالية |
| C3 | طلاقة عربية (تقييم بشري 1–5): متوسط ≥ 4.0، وأفضل من V1 بدلالة | مقيّمان على 50 وحدة لكل مجال، مع قياس الاتفاق |
| C4 | لا عامية: 0 وحدات في الفحص الآلي، و≤ 1% في المراجعة البشرية | قائمة + ALDi كمؤشر + بشر |
| C5 | ملاءمة المدة: ≥ 90% من الوحدات تتسع بلا تسريع أو بتسريع ≤ 1.25 | المدة المتوقعة؛ وبعد TTS المدة الفعلية |
| C6 | صحة النص المنطوق: 100% على حالات النطق الذهبية، و≥ 98% في عينة 100 وحدة | مراجعة `spoken_text` |

## القرار
- **V2 يُقبل ويُدمج في `main`** إذا تحققت كل شروط أ وب وج، وشرط D1.
- **يُقبل بشروط** إذا فشل شرط واحد من ج أو د، مع خطة إصلاح موثّقة.
- **يُرفض** إذا فشل أي شرط من أ أو ب.
