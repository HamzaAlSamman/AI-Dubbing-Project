# خطة تنفيذ إصلاحات Translation V2

**المرجع:** `TRANSLATION_V2_AUDIT.md` (رموز المشاكل P0-1 وما بعده).
**الحالة:** خطة فقط. لا يبدأ أي تعديل إنتاجي قبل موافقتك.

**قاعدة لكل مهمة:**
1. اختبار يفشل أولًا (يثبت المشكلة).
2. ثم الإصلاح.
3. ثم الاختبار ينجح.
4. ثم commit منفصل.

لا تُحذف نتائج قديمة، ولا تتغير معرّفات الوحدات الأصلية.

## المرحلة 3 — التجارب العلمية

يُنفَّذ بعد المراحل 0–2، وبموافقتك على البيانات.

1. **اختيار البيانات:** 3 مجالات × 3 دروس، بتراخيص موثّقة في `datasets/LICENSES.md` (التدقيق §9.2).
2. **المراجع البشرية:** دليل أسلوب مكتوب، ومترجم ومراجع، و20% بمرجعين، وقاموس تقييم مستقل.
3. **تجميد الإعدادات** (commit + hash) قبل فتح دروس الاختبار.
4. **Ablation:** السلسلة B0–E5، وإزالة مكوّن واحد F−x (§8.2)، و3 تكرارات للمكونات العشوائية.
5. **الإحصاء:** McNemar، وpaired bootstrap، وHolm.
6. **التقييم البشري:** 50 وحدة على الأقل لكل مجال: طلاقة 1–5 وMQM مبسّط. وبعد TTS، استماع لطبيعية الكلام.
7. **WMT24++:**
   - إكمال Gemini Flash على 111 مقطعًا، أو حذفه من الجداول.
   - تشغيل Gemini بلا قيد طول للمقارنة العادلة.
   - تقرير chrF++ بتطبيع عربي معلن.
