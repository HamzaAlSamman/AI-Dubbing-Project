# ArabicDubbing V2.11 — Source-first Translation Agent

## القرار المعماري المصحّح

لا نرسل الكورس كاملاً ضمن دفعة واحدة، ولا نفترض وجود ترجمة عربية مسبقة لأي كورس. المدخل هو نص المصدر الناتج عن WhisperX بعد محاذاة الكلمات، ثم تُبنى وحدات Translation Units مع الحفاظ على الكلمات والأزمنة. لا يشغّل هذا الجزء WhisperX نفسه.

## دورة الوكيل

```text
Video / audio → WhisperX ASR + alignment (مرحلة منفصلة)
             → Master SOURCE فقط (بدون ترجمة)
             → Agent PLAN
                ├─ وحدة واحدة + سياق محدود لجمل الجوار
                ├─ قاموس الكورس المعتمد فقط (إن وجد)
                ├─ ذاكرة مصطلحات مؤقتة من المسودات السابقة (غير معتمدة)
                ├─ TRANSLATE: ترجمة دقيقة + طبيعية للإلقاء
                ├─ فحص حتمي للأرقام والرموز والنفي والحدود
                ├─ عند وجود مخاطر: CRITIQUE عبر طلب مستقل
                └─ حفظ Checkpoint ثم الوحدة التالية
             → مراجعة واعتماد المصطلحات والترجمات بشرياً
             → TTS والمزامنة لاحقاً (غير منفّذين في هذه المرحلة)
```

الوحدة تُرسل **منفردة** في كل استدعاء ترجمة، والوكيل يختار خطوة مراجعة إضافية حسب المخاطر، وليس Batch من 15 أو 20 جملة. حتى نتيجة المراجع لا تعني اعتماد النص.

## لكل الكورسات، وليس التجربة القديمة

- لا تُقرأ حقول `natural_ar` أو `accurate_ar` الموجودة لتوجيه الترجمة؛ يُستخدم النص الإنجليزي وحده.
- إذا كانت هناك ترجمة قديمة، تبقى محفوظة لكنها لا تدخل طلب الوكيل الجديد.
- لا تُفرض هوية `pilot_course` أو مجال Machine Learning على كورس مختلف. العنوان المجهول يبقى مجهولاً.
- لا ينتقل قاموس معتمد إلى كورس آخر دون تطابق نطاقه.
- ملفات المصدر و IDs و `source_refs` و `timing` لا تتغير؛ تُحفظ المسودات في ملفات أخرى.

## إدارة الحصة

- `execute=False` افتراضياً، وكل العمليات تخطيط فقط من دون اتصال بمزود.
- التشغيل عبر Gemini يحتاج موافقة الاتصال (`allow_online`) والتحقق من الفئة المجانية (`free_tier_confirmed`). إتاحة الفئة المجانية لا تعني عدم وجود رسوم على مشروع مفوتر.
- `max_new_calls=3` مثال لميزانية تنفيذ **جولة واحدة**، لا يعني أن Gemini محدود بثلاث طلبات في الدقيقة. يمكنك استئناف الجولات من Checkpoints صالحة دون تكرار استدعاء ناجح.
- `rpm_limit` حد محلي ولا يرى استهلاك الخدمات الأخرى أو رصيدك الحقيقي. عند خطأ الحصة 429 يتوقف التنفيذ ولا يعيد المحاولة تلقائياً.
- `review_policy='flagged'` للمراجعة الانتقائية، أو `all` لمراجعة كل وحدة (طلب إضافي)، أو `none` بلا مراجع آلي؛ جميعها تتطلب مراجعة بشرية لاحقاً.
- يمكن استخدام backend محلي على Colab GPU مستقبلاً، لكن الربط الفعلي لنموذج محلي لم يُختبر في هذا الإصدار.

## Checkpoints

يحفظ النظام ملف `translate_*.json` لكل وحدة و`review_*.json` عند المراجعة، دون الكتابة فوق الملفات الموجودة. الاستئناف يعيد التحقق من هوية الوحدة وبصمة المهمة وChecksum النتائج، ويرفض نتائج مصدر مختلف أو ترجمات تمت الموافقة عليها بلا دليل. كل المخرجات `human_approved=False` و`final_dub_ar=None`.

## النواقص قبل إنتاج فيديو مدبلج

التحقق المستقل من الدقة الدلالية على مصادر حقيقية من تخصصات مختلفة، اختيار واستضافة backend محلي فعلي، قياس Tokens للطلب والاستجابة، ذاكرة تعلّم معتمدة ممتدة عبر الدروس، مراجعة بشرية، اختبار الصوت والمزامنة. الاختبارات الحالية باستخدام backends وهمية ولا تثبت جودة ترجمة نموذج حقيقي.

## تجربة التخطيط بلا API

```python
from arabic_dubbing_v2.translation_agent_v211 import plan_agent, execute_agent
from arabic_dubbing_v2.common import read_json
master = read_json('/path/to/NEW_course_source_master.json')
plan = plan_agent(master, context_window=2)
result = execute_agent(plan, master, '/tmp/agent_candidates')
print(result)  # zero API calls
```
